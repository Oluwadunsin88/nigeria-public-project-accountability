 Project Data

This folder contains the datasets and outputs used in the Nigeria Public Project Accountability Intelligence System.

 Files
- `anambra_project_audit.csv` — overall project data audit.
- `anambra_flagged_projects.csv` — records flagged for further review based on data-quality checks.
- `anambra_flag_counts.csv` — summary of review flags.
- Additional CSV files contain SQL analysis results and the source dataset.

Important: A review flag indicates that a record needs further examination; it does not establish project failure, fraud, or mismanagement.
